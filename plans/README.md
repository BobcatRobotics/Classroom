## Findings considered and rejected (so they are not re-audited)

- **Idle reap killing active runs**: rejected. `last_accessed_at` IS bumped by
  `touchWorkspace` inside `requireWorkspaceOwnership` (`auth/middleware.ts:118`),
  and the web shell polls `/api/sim/status` + `/api/sim/auto-choosers` every ~1s
  through that path, so an active session is continuously kept fresh and will not
  be reaped.
- **No tracked secrets**: verified `.env` is gitignored and only `.env.example`
  (placeholders, no real values) is tracked. No action needed.
- **ZIP upload path traversal (`app/assets.ts:317`)** and **admin restore
  tarball (`admin-routes.ts:185`)**: LOW confidence, depend on host `unzip`/`tar`
  traversal behavior, and the restore path is admin-only. Not worth a fix plan
  until traversal behavior is actually demonstrated; revisit only with a repro.
- **NT4 `Math.random()` pubuid collision / int64 precision loss
  (`nt4-auto.ts:597,300`)**: real but improbable and self-limiting (chooser
  strings only). Not worth dedicated plans.
- **Metrics gauge reset-before-populate (`metrics-collector.ts`)**: cosmetic
  dashboard gap on a transient docker failure; low leverage.
- **Mutating HTTP routes rely on SameSite=Lax only (no Origin check)**: real but
  low severity (JSON content-type + Lax blocks form-based CSRF). Folded into the
  maintenance notes of plan 003 rather than its own plan; revisit if SameSite is
  ever loosened.
