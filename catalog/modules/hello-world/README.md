# Hello, World

A bare-bones Java project to make sure everything works. The code lives in
`src/Main.java`.

## Running it

Click the editor **Run** button. You should see `Hello, World!` printed in the
terminal.

## Try stuff

This is your sandbox — change the code and run it again. Print something else,
add variables, do some math, write a loop. There's nothing to break, so
experiment and see what happens.
