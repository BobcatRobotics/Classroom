# Hello, Name

Work in `src/Main.java`. Run this lesson with the editor Run button.

## Steps

1. Store your name in a `String` variable.
2. Print `Hello, <name>` with `System.out.println`.
3. Use a `Scanner` to ask the user for their name, then greet that name.
4. Get today's date automatically and print it too.
5. Ask for the user's age and print it.

## Bonus

- Handle bad input without crashing.
- Ask for first and last name separately.
- Add one or two more questions and print a short summary.
